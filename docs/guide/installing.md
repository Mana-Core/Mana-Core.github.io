# Installing extensions

Mana loads 3rd Party sources from a URL you add once; after that, the source and any others published alongside it are available to install, and updates arrive automatically.

## 1. Find a source

Open the [Source Index](/extensions/) and search or filter for the site you want.

## 2. Install it

Press **Install** on the source's card. Mana opens and shows the source; confirm to install it. Each source updates on its own when its repository publishes a new version.

## Adding a repository by hand

If Mana doesn't open, update it to the latest version. You can also add the whole repository from the [Source Index](/extensions/): pick it in the filters and press **Add to Mana**. Its sources then appear in Mana, ready to install.

::: info
Menu labels can change between Mana releases. If you can't find the option, check the release notes of your Mana version.
:::

## Content ratings

Every source declares a rating, shown as a badge on its card:

| Badge | Meaning |
| --- | --- |
| <span class="mc-chip safe">Safe</span> | Suitable for everyone. |
| <span class="mc-chip mixed">Mixed</span> | May contain some mature titles. |
| <span class="mc-chip nsfw">NSFW</span> | Primarily explicit content. Hidden on this site unless you turn on **NSFW Sources** in settings (<span class="mc-icon i-settings"></span>). |
